Politique de confidentialité

Dernière mise à jour : 12/10/2026

Présentation

Ce projet est un projet étudiant réalisé dans le cadre d’un mémoire de master. Il utilise n8n pour répondre automatiquement aux commentaires publiés sur la page Facebook Flangia.

Contact : annieflangiaaugustine@gmail.com

Données collectées

Lorsqu’un utilisateur publie un commentaire sur la page Facebook, nous collectons via l’API Meta :

  • le contenu du commentaire ;
  • la date et l’heure ;
  • le nom public et l’identifiant Facebook de l’auteur ;
  • l’identifiant de la publication.

Utilisation

Ces données servent uniquement à générer et publier une réponse automatique au commentaire.

Partage

Les données sont traitées par Meta Platforms Inc. (API Facebook) et par n8n pour l’automatisation. Aucune donnée n’est vendue.

Conservation

Les données sont conservées [30] jours maximum, puis supprimées.

Suppression des données

Pour demander la suppression de vos données, envoyez un e-mail à annieflangiaaugustine@gmail.com avec l’objet « Suppression données Facebook ». Nous traiterons votre demande sous 30 jours.

Vous pouvez également retirer l’application dans Facebook : Paramètres > Applications et sites web.
